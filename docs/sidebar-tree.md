# Sidebar TREE

Enable TREE under Layout → Tabs → shown → Configure tabs → TREE: on. It is disabled by default; existing preferences keep their previous MAIN and GIT choices. The fullscreen rail appears at 140 columns or wider.

TREE starts at the current session directory. In a Git worktree, choose MAIN or WORKTREE above the tree to browse that root and its own Git status without changing the session directory. When both roots coincide only MAIN is shown; outside Git the tree remains available without a selector. Click directories to expand or collapse them and use the mouse wheel to scroll the tree. Directory contents load asynchronously only when expanded; reopening a directory refreshes its cached contents without hiding them. Directory symlinks and observed symlink ancestors are not traversed. Ancestor checks are best effort, not atomic: concurrent replacement can race them. Click a file to open Gentle's read-only viewer. Use ↑/↓ or the wheel to scroll and Esc to close. Long lines wrap to the viewport; visual continuations have a small extra indentation. Tabs align to eight-column stops; blank lines and indentation remain visible. Very narrow terminals must be widened to display content, and previews with more than 8192 wrapped rows show a display-truncation notice. The viewer reads at most 128 KiB and reports truncation, binary files and errors. Symlinks and special files are rejected. Ancestor checks are best effort: concurrent directory replacement can race them, so this is not a security boundary.

Git status marks modified, untracked, added, deleted, renamed and conflicted files with `M`, `U`, `A`, `D`, `R` and `!`; a dot marks directories containing changes. Deleted paths remain visible. Refreshes follow successful write, edit and bash tools and turn completion while TREE is active. On a failed refresh the previous contents or Git status remain visible with an error indication.
